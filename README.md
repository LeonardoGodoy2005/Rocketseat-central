# 🚀 Rocketseat Web Projects

Coleção de projetos desenvolvidos durante meus estudos de desenvolvimento web, com foco em **HTML, CSS, JavaScript e design responsivo**.

Cada projeto explora diferentes desafios de construção de interfaces, organização de conteúdo e experiência do usuário, aplicando conceitos fundamentais do desenvolvimento Front-End.

## 📂 Projetos

### ✈️ [Wayfarer — Travel Profile](https://github.com/LeonardoGodoy2005/Wayfarer)

Interface de perfil de viagens desenvolvida com HTML e CSS.

### 📰 [The Daily — News Portal](https://github.com/LeonardoGodoy2005/The-Daily)

Portal de notícias responsivo desenvolvido com HTML e CSS.

**Repositório:** adicione aqui o link correto do The Daily.

### 🎓 [Enrollly — Enrollment Form](https://github.com/LeonardoGodoy2005/enrollly)

Formulário de matrícula responsivo com HTML, CSS e JavaScript, incluindo validação de campos e feedback visual.


## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação semântica das páginas.
- **CSS3:** estilização, layouts e responsividade.
- **JavaScript:** interatividade e validação de formulários.

## 🎯 Objetivos

- Praticar os fundamentos do desenvolvimento Front-End.
- Criar interfaces responsivas e organizadas.
- Aplicar boas práticas de estruturação e estilização.
- Desenvolver projetos práticos para meu portfólio.
- Evoluir continuamente como desenvolvedor.
